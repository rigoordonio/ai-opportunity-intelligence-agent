# AI Opportunity Intelligence Agent

An automated Business Development intelligence platform powered by Ollama and Qwen.

## Features

- Monitors strategic energy accounts
- Retrieves latest public news
- Uses local AI (Qwen3:14b)
- Generates executive opportunity summaries
- Sends daily email intelligence reports
- Runs automatically via cron

## Accounts Monitored

- Shell
- ADNOC
- Aramco
- Woodside
- Petrofac

## Technology Stack

- Python
- Ollama
- Qwen3:14b
- Feedparser
- Gmail SMTP
- Cron
